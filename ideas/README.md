# Idea catalogue

Every idea we could find on [bay12games.com](https://www.bay12games.com/dwarves/) that fits a
fortress, deduplicated and compared with what DwarfClone has (October 2026). All of it is in our
own words; nothing is copied, and the code stays original.

**Where it came from:** Tarn's bloat list (Bloat#1-383, from 2009 archives), the roadmap pages
past and present (Core, Requests, Power Goals and the arcs, 2009-2025), the development log
from 2006 to 2026 with the release notes of every major version, Threetoe's 42 stories (read
as design targets: what would a game need to tell this?), and the features page. Each idea
cites its sources: `Bloat#n`, `Core#`/`Req#`/`PG#`, `Log20xx`, `Rel0.xx`, `Story:<title>`.

**How to read an idea:** an ID (`MIL-03`), the mechanic, its status here (Have / Partial /
Planned / Missing), a size (S one session, M a few, L a big system) and how much fun it would
be in an overseer-run fort (★ to ★★★). The **Roadmap** column names the WISHLIST item that will
build it; 562 of the 932 ideas are placed, the rest wait here.

**[atlas.html](atlas.html)** shows all of it in a browser: the roadmap with each item's ideas,
Dwarf Fortress and DwarfClone compared domain by domain, and every idea, searchable and filterable.
Open it straight from disk; it needs no server.
